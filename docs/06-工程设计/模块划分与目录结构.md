## C++ 模块

### `src/bin`

`main.cpp` 是进程入口，负责加载配置、设置静态资源、注册路由并启动 Drogon。

### `src/service`

`ApiRoutes` 是当前唯一路由聚合类，路由按文件拆分：

1. `register_products_routes.cc`
2. `register_document_routes.cc`
3. `register_release_routes.cc`
4. `register_check_update_routes.cc`
5. `register_convert_task_routes.cc`
6. `register_convert_task_status_routes.cc`
7. `register_convert_task_result_routes.cc`

### `src/action`

当前 action：

1. `ProductsAction`
2. `DocumentAction`
3. `CheckUpdateAction`
4. `ConvertDataTaskAction`

历史目录名 `src/action/CheckUpdataAction` 存在拼写遗留，但类名和头文件是 `CheckUpdateAction`。

### `src/storage`

当前没有拆分 repository；所有 SQLite 能力先集中在 `Storage_SQL`：

1. `storage.cc`：连接、迁移、prepared statement helper。
2. `getALLProducts.cc`
3. `getALLReleases.cc`
4. `getALLPackages.cc`
5. `getDocument.cc`
6. `getLatestRelease.cc`
7. `getConvertRule.cc`
8. `addTask.cc`
9. `getTask.cc`
10. `updateTask.cc`

### `src/tools`

当前工具：

1. `canupgrade.cc`
2. `md5.cc`
3. `sha256.cc`
4. `TimestampString.cc`

## 构建配置

`CMakeLists.txt` 当前自动收集：

1. `src/action/*.cc`
2. `src/service/*.cc`
3. `src/storage/*.cc`
4. `src/tools/*.cc`

并链接：

1. `Drogon::Drogon`
2. `spdlog::spdlog`
3. `nlohmann_json::nlohmann_json`
4. `sqlite3`
5. `OpenSSL::Crypto`

## 约束

1. 新 HTTP API 优先放在 `src/service/register_*_routes.cc`，不要塞进 `main.cpp`。
2. 新业务流程优先放在 `action`，不要让 service 直接访问 SQLite。
3. 新 SQLite 查询优先进入 `Storage_SQL`，后续再按需要拆 repository。
4. 文档中的接口路径和字段必须以当前代码为准。
