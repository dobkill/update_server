## 约束

1. HTTP 路由只放在 `src/service/register_*_routes.cc`。
2. service 不直接访问 SQLite。
3. action 负责业务编排。
4. storage 负责 SQLite 查询和写入。
5. Web 首页真实作品只来自 `/api/v1/portfolio-home`。
6. 管理员脚本只通过命令行运行。
