# 项目概述

本项目是一个 C++/Drogon 服务，包含两条清晰分离的能力：

1. 个人软件作品集网站：展示自研软件、工具、系统和实验项目。
2. 软件更新平台：提供版本发布文档、更新检查、安装包信息和数据转换任务。

## 当前设计原则

1. Web 作品集使用独立的 `portfolio_projects` 模型。
2. 软件更新能力继续使用 `products/releases/release_assets/release_channels` 模型。
3. Web 作品集不再复用软件更新模型拼装页面。
4. 不保留旧 Web 兼容接口。
5. 前端没有 mock fallback，接口不可用时直接显示错误状态。

## 核心接口

作品集：

```http
GET /api/v1/projects
GET /api/v1/projects/{slug}
```

软件更新：

```http
GET /api/v1/products/{product_code}/document
GET /api/v1/products/{product_code}/releases
GET /api/v1/products/{product_code}/check-update/{version}
POST /api/v1/products/{product_code}/convert-tasks
GET /api/v1/products/{product_code}/convert-tasks/{task_id}/status
GET /api/v1/products/{product_code}/convert-tasks/{task_id}/result
```

## 前端页面

```text
/                 作品集首页
/projects/{slug}  项目案例详情
```

## 数据库

空库执行 `migrations/002.init.sql`。已有库启动时通过 `Storage_SQL::ensurePortfolioProjectSchema()` 补齐作品集结构。
