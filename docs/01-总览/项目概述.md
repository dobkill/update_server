# 项目概述

## 项目目标

本项目是 C++/Drogon 软件更新平台，提供：

1. Web 个人作品集首页。
2. 产品版本详情页。
3. 客户端更新检查接口。
4. 数据转换任务创建、状态查询与结果查询。
5. SQLite 元数据管理。
6. Python 管理、迁移、导出、导入脚本。

## 可运行能力

1. 后端通过 `cmake --build build -j2` 构建。
2. `src/bin/main.cpp` 注册 API 路由并服务 `web/dist`。
3. `Storage_SQL` 打开 `config/app.json` 中配置的 SQLite 路径。
4. 空库执行 `migrations/002.init.sql`。
5. 已有库通过 `Storage_SQL::ensurePortfolioSchema()` 补齐首页相关表和字段。
6. 首页通过 `/api/v1/portfolio-home` 获取聚合数据。
7. 版本详情通过 `/api/v1/products/{product_code}/document` 和 `/Document` 获取。
8. 数据转换任务由 C++ worker 调用 `python/convert/convert_data.py`。

## 模块划分

| 模块 | 职责 |
| --- | --- |
| `web` | Vue 首页、版本详情页、构建产物 |
| `service` | Drogon 路由注册、HTTP 参数解析、JSON 响应 |
| `action` | 首页聚合、产品列表、版本文档、更新检查、转换任务 |
| `storage` | SQLite 查询、写入、运行时结构补齐 |
| `tools` | 版本比较、MD5、SHA256、时间戳 |
| `config` | 应用路径、Drogon 监听配置、Daily 入库配置 |
| `python` | 管理入口、数据库迁移、导出、导入、数据转换 |

## 依赖方向

```text
Browser / Client
  -> web/dist
  -> service
  -> action
  -> storage
  -> SQLite / data/

ConvertDataTaskAction
  -> python/convert/convert_data.py
```

## 配置文件

1. `config/app.json`
2. `config/drogon_config.json`
3. `config/daily_release.toml`

SQLite 访问统一由 `Storage_SQL` 管理。
