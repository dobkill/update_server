# 项目概述

## 项目目标

本项目是一个 C++/Drogon 软件更新平台，目标是提供：

1. Web 产品列表与版本详情页。
2. 客户端更新检查接口。
3. 数据转换任务创建、状态查询与结果查询。
4. SQLite 元数据管理与 `data/` 文件目录管理。

## 当前可运行能力

1. 后端可通过 `cmake --build build -j 2` 构建。
2. `src/bin/main.cpp` 已接入 `Router::ApiRoutes::Instance()`，启动时会注册所有当前路由。
3. `Storage_SQL` 会打开 `config/app.json` 中配置的 SQLite 路径，并在空库或缺少 `products` 表时执行 `migrations/002.init.sql`。
4. `web/dist` 会作为静态站点根目录；浏览器访问 `/` 可以加载前端页面。
5. 数据库为空时，接口返回空列表或业务 `404`，服务本身仍是正常运行状态。

## 模块划分

| 模块 | 当前职责 |
| --- | --- |
| `web` | Vue 前端与已构建的 `web/dist` 静态资源 |
| `service` | Drogon 路由注册、HTTP 参数解析、JSON 响应返回 |
| `action` | 产品、文档、更新检查、转换任务业务编排 |
| `storage` | sqlite3 prepared statement 查询、任务写入、迁移初始化 |
| `tools` | 版本比较、MD5、SHA256、时间戳工具 |
| `config` | 应用路径与 Drogon 监听配置 |
| `python` | 数据转换脚本与维护脚本 |

## 依赖方向

```text
Browser / Client
  -> web/dist
  -> service
  -> action
  -> storage
  -> SQLite / data/

action
  -> python/convert/convert_data.py
```

## 配置文件

1. `config/app.json`：数据库路径、上传目录、转换输出目录、转换脚本路径、worker 数等应用配置。
2. `config/drogon_config.json`：Drogon HTTP 线程、静态目录、上传路径、监听端口等服务配置。

当前项目没有使用 Drogon 自带 `db_clients`，SQLite 访问统一由 `Storage_SQL` 管理。
