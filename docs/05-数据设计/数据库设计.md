# 数据库设计

数据库结构以 `migrations/002.init.sql` 为准。`Storage_SQL` 启动时打开 `config/app.json` 中的 `database_path`，空库执行初始化 SQL，已有库通过 `ensurePortfolioProjectSchema()` 补齐作品集相关结构。

实际文件保存在 `data/`，SQLite 保存元信息、路径、状态、作品集项目和任务记录。

## 表结构总览

| 表 | 用途 |
| --- | --- |
| `schema_migrations` | 结构迁移版本 |
| `site_profile` | 作品集站点资料 |
| `portfolio_projects` | Web 作品集项目案例 |
| `products` | 软件产品本体，服务更新发布能力 |
| `releases` | 产品版本 |
| `release_assets` | 全量包 |
| `release_channels` | 渠道 latest 指针 |
| `update_packages` | 增量包或补丁包 |
| `convert_rules` | 数据结构版本转换规则 |
| `convert_tasks` | 数据转换任务 |

当前作品集结构迁移版本：

```text
20260607_portfolio_projects
```

## site_profile

字段：

1. `id`
2. `owner_name`
3. `site_name`
4. `subtitle`
5. `hero_label`
6. `hero_title`
7. `hero_description`
8. `github_url`
9. `email`
10. `resume_url`
11. `linkedin_url`
12. `twitter_url`
13. `created_at`
14. `updated_at`

约束：

```text
id = 1
```

Web 顶部导航、Hero 和 Footer 均来自 `site_profile`。

## portfolio_projects

字段：

1. `id`
2. `product_id`
3. `slug`
4. `name`
5. `category`
6. `description`
7. `long_description`
8. `featured`
9. `status`
10. `year`
11. `platform`
12. `role`
13. `project_type`
14. `cover_image_url`
15. `hero_image_url`
16. `tech_stack_json`
17. `features_json`
18. `screenshots_json`
19. `architecture_json`
20. `challenge`
21. `solution`
22. `result`
23. `links_json`
24. `visibility`
25. `sort_order`
26. `created_at`
27. `updated_at`

约束：

```text
slug 唯一
featured IN (0, 1)
visibility IN ('public', 'hidden')
product_id 可为空；不为空时关联 products.id
```

JSON 字段：

1. `tech_stack_json`：技术栈数组。
2. `features_json`：核心功能数组。
3. `screenshots_json`：真实截图对象数组，单项结构为 `{ "title": "...", "desc": "...", "image": "/data/..." }`。
4. `architecture_json`：架构流程节点数组。
5. `links_json`：链接对象，例如 `liveDemo`、`github`。

查询索引：

1. `idx_portfolio_projects_public_order`
2. `idx_portfolio_projects_category`

## products

字段：

1. `id`
2. `name`
3. `code`
4. `github_url`
5. `description`
6. `icon_path`
7. `status`
8. `created_at`
9. `updated_at`

`products` 不再承担 Web 作品集展示模型，只服务软件发布、更新检查和转换任务。若某个作品集项目对应一个真实软件产品，可通过 `portfolio_projects.product_id` 关联。
