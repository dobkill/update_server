# 版本更新模块

## 1. 目标

为客户端提供稳定的版本检查、全量安装包下载、历史版本查看和版本详情文档查看能力。

## 2. 模块分工

| 模块 | 职责 |
| --- | --- |
| `web` | 展示产品列表、版本列表、版本详情页和下载入口 |
| `service` | 接收更新检查请求、版本查询请求、文档请求和下载请求 |
| `action` | 选择目标版本、判断是否需要更新、读取文档数据、处理最新版本切换 |
| `storage` | 访问版本元数据、详情页资源和安装包文件 |
| `scripts` | 由管理员人工执行 Python 脚本，发布包体、计算摘要、批量导入版本数据 |

推荐 action 命名：

1. `ProductsAction`
2. `ReleasesAction`
3. `DocumentAction`
4. `CheckUpdateAction`
5. `DownloadAction`

## 3. 业务流程

### 3.1 客户端更新检查

```text
客户端提交 client_version / platform / arch / channel
-> service 校验参数
-> action 选择 product + channel 的最新版本并比较版本号
-> storage 读取版本元数据和包体元数据
-> service 返回 need_update / latest_version / release_notes_summary / download.url
-> 客户端直接使用 download.url 下载全量安装包
```

### 3.2 版本文档查询

```text
web 调用 /api/v1/products/{product_code}/Document?version=...&channel=...
-> service 校验参数
-> action 解析 requested_version
-> 若 requested_version 为空、缺省或 latest，则按 channel 解析最新版本
-> storage 读取版本对象、页面对象和下载所需元数据
-> service 返回 requested_version / resolved_version / page.page_data
```

### 3.3 下载流程

```text
客户端调用 /api/v1/products/{product_code}/releases/{version}/download?platform=...&arch=...&channel=...
-> service 校验参数
-> action 确定目标包体
-> storage 读取包体路径
-> service 返回 302 跳转
```

## 4. 核心模型拆分

版本更新模块中的核心对象建议固定为：

1. `Product`
   表示对外产品入口。
2. `Release`
   表示逻辑版本，包含版本号、渠道、标题、摘要、发布时间。
3. `ReleasePackage`
   表示某逻辑版本下特定平台和架构的安装包。
4. `ReleasePage`
   表示某产品某版本共享的版本详情页资源，同一 `version` 跨渠道共用。

必须遵守以下原则：

1. `Release` 与 `ReleasePackage` 必须拆分，不能用单表同时表达逻辑版本和包体文件。
2. “最新版本”应由 `product_code + channel -> release` 指针解析，不建议使用包体行上的 `is_latest`。
3. 详情页入口路径和页面数据路径属于 `ReleasePage`，不与包体字段混放。
4. 同一 `product_code + version` 的详情页内容跨渠道共享，`channel` 只影响 latest 解析、存在性校验和下载包选择。

## 5. 设计规则

1. `service` 只负责接口协议，不直接比较版本或切换状态。
2. 版本选择和最新版本切换都归 `action`。
3. 当前阶段只支持全量更新，不实现增量更新、增量兜底和兼容逻辑。
4. `update-check` 返回 `latest_version`，并在需要更新时直接返回 `download.url`。
5. 包体文件始终存放在 `data/packages/`。
6. 下载包通过 `product_code + version + platform + arch + channel` 唯一定位。
7. 版本详情文档统一通过 `GET /api/v1/products/{product_code}/Document` 查询，使用 Query 参数 `version` 表达版本选择；旧 `/releases/latest` 完全废弃。
8. `version` 为空、缺省或 `latest` 都表示按渠道解析最新版本。
9. 若显式传入 `channel` 且目标版本在该渠道下不存在，直接返回 `404`。
10. `storage` 返回版本对象、包体对象和页面对象，不直接返回某个 API 的拼装 JSON。
11. 不在正式业务表中保存 `project_path`、源码目录和 Vue 源码路径。

## 6. 发布原则

1. 管理员在服务器本机人工执行 `python/` 下发布脚本。
2. 先导入包体到暂存目录。
3. 计算 `SHA256`、大小与版本信息。
4. 直接写入 SQLite 元数据和 `data/` 目录内容。
5. 通过事务切换 `product + channel` 的最新版本指针。
6. 发布成功后，客户端下一次查询立即读取到新版本。
