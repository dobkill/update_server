# 数据转换模块

## 能力

数据转换模块由 `ConvertDataTaskAction` 和 `python/convert/convert_data.py` 组成：

1. 创建转换任务。
2. 查询任务状态。
3. 查询任务结果。
4. worker 线程异步执行转换脚本。

## 接口

创建任务：

```http
POST /api/v1/products/{product_code}/convert-tasks?from_version=1&to_version=2
```

查询状态：

```http
GET /api/v1/products/{product_code}/convert-tasks/{task_id}/status
```

查询结果：

```http
GET /api/v1/products/{product_code}/convert-tasks/{task_id}/result
```

## 创建任务流程

```text
service 保存 body 到 upload_task_dir
  -> ConvertDataTaskAction::createTask()
  -> Storage_SQL::getProduct()
  -> Storage_SQL::getConvertRule()
  -> Storage_SQL::addTask()
  -> 内存队列 pending
  -> worker running
  -> python3 convert_data.py
  -> Storage_SQL::updateTaskStatus()
```

## 转换脚本调用

```bash
python3 <script_path> \
  --input <input_file_path> \
  --output <output_file_path> \
  --source-version <from_version> \
  --target-version <to_version>
```

默认脚本为 `config/app.json` 中的 `convert_script`。任务执行使用 `convert_rules.script_path`。

## 转换脚本目录

```text
python/convert/
├── __init__.py
├── convert_data.py
└── <product_code>/
    └── convert_v1_to_v2.py
```

`convert_rules.script_path` 可指向产品目录中的转换脚本。

## 状态

1. `pending`
2. `running`
3. `success`
4. `failed`
5. `canceled`

## 行为边界

1. service 把请求 body 作为原始文件内容保存。
2. 任务状态同时保存在内存 `task_map` 和 SQLite `convert_tasks`。
3. 进程重启后，状态和结果接口查询 SQLite。
4. 输出文件路径作为 `download_url` 返回。
