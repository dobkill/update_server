# Action 列表
1. `ProductsAction`    
2. `DocumentAction`   
3. `CheckUpdateAction`  
4. `DownloadAction`   


# Action 分工详情
1) `ProductsAction`：
    负责无参主页 web 页面所需的信息

2) `DocumentAction`：
    负责：详情页 web 所需的信息
    【1】产品 release / 版本详情文档
    【2】产品 web 介绍页
    【3】产品 web 下载页
3) `CheckUpdateAction`：
    负责：客户端更新检查
    [1] 检查更新
    [2] 操作引导

4) `DownloadAction`：
    负责：客户端下载更新包
    [1] 增量下载
    [2] 全量下载
