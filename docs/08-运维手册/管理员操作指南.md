# 管理员操作指南

## 管理入口

交互式入口：

```bash
python python/admin/admin.py
```

自动化写入：

```bash
ADMIN_CONFIG=config/daily_release.toml ADMIN_DRY_RUN=0 python python/admin/admin.py
```

预演：

```bash
ADMIN_CONFIG=config/daily_release.toml ADMIN_DRY_RUN=1 python python/admin/admin.py
```

## TOML 配置块

执行顺序：

1. `site_profile`
2. `product`
3. `future_direction`
4. `recommendation`
5. `release`
6. `release.asset`
7. `release.channel`
8. `update_package`
9. `convert_rule`
10. `page_publish`
11. `page_offline`
12. `page_rollback`
13. `cleanup`

`config/daily_release.toml` 包含 Daily 首页和版本入库数据。

## 数据库迁移

执行结构迁移：

```bash
python python/admin/migrate_sqlite.py --db ./data/database/update_platform.db
```

迁移脚本会：

1. 备份数据库。
2. 创建 `schema_migrations`。
3. 补齐 `products.github_url`。
4. 创建或补齐 `product_careers`。
5. 创建或补齐 `recommendations`。
6. 创建或补齐 `site_profile`。
7. 创建或补齐 `future_directions`。
8. 写入 `20260606_portfolio_home` 迁移版本。

## 数据导出

```bash
python python/admin/export_sqlite_json.py \
  --db ./data/database/update_platform.db \
  --out ./data/backups/update_platform.json
```

覆盖已有导出文件：

```bash
python python/admin/export_sqlite_json.py \
  --db ./data/database/update_platform.db \
  --out ./data/backups/update_platform.json \
  --overwrite
```

## 数据导入

```bash
python python/admin/import_sqlite_json.py \
  --db ./data/database/update_platform.db \
  --in ./data/backups/update_platform.json \
  --mode upsert
```

导入模式：

1. `insert`
2. `upsert`
3. `replace`

导入前会备份目标数据库。
