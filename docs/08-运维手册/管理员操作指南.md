# 管理员操作指南

管理员工具位于 `python/admin/`。当前只保留一个统一入口：

```bash
python python/admin/admin.py
```

入口会扫描 `config/*.toml`，让管理员选择要执行的配置文件，并默认先预演不写库。确认结果后再次运行，在提示中选择写入数据库。

自动化场景使用环境变量，不再使用命令行参数：

```bash
ADMIN_CONFIG=config/daily_release.toml ADMIN_DRY_RUN=0 python python/admin/admin.py
```

## TOML 配置

常用配置块：

```toml
[[product]]
name = "Daily"
code = "Daily"
description = "Obsidian 插件，用来管理每日任务、快速记录和项目规划进度。"
icon_path = "/data/releases/Daily/v1.0.0/icon/image.png"
status = "active"

[[release]]
product_code = "Daily"
version = "v1.0.0"
release_note = "Daily v1.0.0 首个可用版本。"
data_schema_version = "v1.0.0"
status = "active"
vue_path = "/data/releases/Daily/v1.0.0/vue/DailyReleasePage.vue"

[[release.asset]]
platform = "obsidian"
arch = "any"
package_type = "plugin"
file_path = "./data/packages/Daily/v1.0.0/Daily-v1.0.0.zip"
auto_hash = true
auto_size = true

[[release.channel]]
channel = "stable"
is_latest = true
```

执行顺序由 `DeployRunner` 自动编排：

1. `product`
2. `release`
3. `release.asset`
4. `release.channel`
5. `update_package`
6. `convert_rule`
7. `page_publish / page_offline / page_rollback`
8. `cleanup`

已存在的产品、版本、包或转换规则会跳过并返回已有 ID；渠道记录已存在时会更新 latest 状态。

## Daily 入库

本次已新增 `config/daily_release.toml`，并将 Daily 写入 SQLite：

| 表 | 关键值 |
| --- | --- |
| `products` | `code = Daily` |
| `releases` | `version = v1.0.0`, `data_schema_version = v1.0.0` |
| `release_assets` | `platform = obsidian`, `arch = any`, `package_type = plugin` |
| `release_channels` | `channel = stable`, `is_latest = 1` |

Daily 插件包由 `data/releases/Daily/v1.0.0/code/` 下的 `main.js`、`manifest.json`、`styles.css` 生成：

```text
data/packages/Daily/v1.0.0/Daily-v1.0.0.zip
```

## 页面清单

版本详情页优先读取：

```text
data/releases/<product_code>/<version>/vue/page.json
```

Daily 当前页面清单为：

```text
data/releases/Daily/v1.0.0/vue/page.json
```

该清单使用 `HeroBlock`、`FeatureGridBlock`、`RichTextBlock`、`ScreenshotGalleryBlock`、`TimelineBlock`、`DownloadPanelBlock`、`FaqBlock` 和 `FooterCtaBlock` 装配页面。

## 平台字段

`release_assets.platform` 当前支持：

1. `windows`
2. `linux`
3. `macos`
4. `obsidian`

`release_assets.arch` 当前支持：

1. `x64`
2. `arm64`
3. `x86`
4. `any`
