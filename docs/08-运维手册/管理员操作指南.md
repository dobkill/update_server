# 管理员操作指南

管理员入口：

```bash
python python/admin/admin.py
```

自动化执行：

```bash
ADMIN_CONFIG=config/daily_release.toml ADMIN_DRY_RUN=1 python python/admin/admin.py
ADMIN_CONFIG=config/daily_release.toml ADMIN_DRY_RUN=0 python python/admin/admin.py
```

## 配置块

`admin.py` 支持以下配置块：

1. `site_profile`
2. `product`
3. `portfolio_project`
4. `release`
5. `release.asset`
6. `release.channel`
7. `update_package`
8. `convert_rule`
9. `page_publish`
10. `page_offline`
11. `page_rollback`
12. `cleanup`

## 数据库迁移

```bash
python python/admin/migrate_sqlite.py
```

当前迁移版本：

```text
20260607_portfolio_projects
```

迁移行为：

1. 备份现有数据库。
2. 补齐 `site_profile` 新字段。
3. 创建 `portfolio_projects`。
4. 清理旧版作品集样例项目，不写入默认假项目。
5. 记录 `schema_migrations`。

## 导出导入

导出：

```bash
python python/admin/export_sqlite_json.py --out data/backups/export.json
```

导入：

```bash
python python/admin/import_sqlite_json.py --db data/database/update_platform.db --in data/backups/export.json --mode upsert
```
