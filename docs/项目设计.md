# 软件更新平台项目设计

## 文档入口

本文档索引 `docs/` 下的项目文档。接口、数据结构、文件路径以代码和本目录文档为准。

## 运行状态

1. `src/bin/main.cpp` 加载配置、注册 `ApiRoutes`、服务 `web/dist`、启动 HTTP 服务。
2. `service` 注册首页聚合、产品列表、版本文档、版本列表、更新检查、转换任务接口。
3. `action` 包含 `ProductsAction`、`DocumentAction`、`CheckUpdateAction`、`ConvertDataTaskAction`。
4. `storage` 使用 sqlite3 prepared statement 访问 SQLite。
5. `Storage_SQL` 执行空库初始化和首页结构补齐。
6. `web` 首页通过 `/api/v1/portfolio-home` 渲染真实作品集。
7. Python 脚本提供管理入口、迁移、导出、导入。

## 构建与运行

```bash
cmake -S . -B build
cmake --build build -j2
./build/software_update_platform
```

Web 构建：

```bash
cd web
npm run typecheck
npm run build
```

验证接口：

```bash
curl http://127.0.0.1:8080/api/v1/portfolio-home
curl http://127.0.0.1:8080/api/v1/products
curl "http://127.0.0.1:8080/api/v1/products/Daily/document?version=latest&channel=stable"
```

## 依赖原则

1. `service -> action -> storage`。
2. service 不直接访问 SQLite。
3. storage 不返回 Drogon 类型。
4. 转换任务由 action 调用 `python/convert/convert_data.py`。
5. 管理员脚本不进入 HTTP 路由。
