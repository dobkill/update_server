# 项目设计

## 当前目标

本项目同时提供：

1. 个人软件作品集网站。
2. 软件更新与数据转换服务。

两者共享 Drogon 服务和 SQLite 存储，但数据模型分离。

## 作品集链路

```text
web/src/main.ts
  -> fetchProjects()
  -> GET /api/v1/projects
  -> ProjectsAction::ListProjects()
  -> Storage_SQL::getPortfolioProjectList()
  -> portfolio_projects
```

详情：

```text
/projects/{slug}
  -> fetchProjectDetail(slug)
  -> GET /api/v1/projects/{slug}
  -> ProjectsAction::GetProjectDetail(slug)
  -> Storage_SQL::getPortfolioProjectDetail(slug)
```

## 更新链路

```text
GET /api/v1/products/{product_code}/document
GET /api/v1/products/{product_code}/releases
GET /api/v1/products/{product_code}/check-update/{version}
POST /api/v1/products/{product_code}/convert-tasks
```

更新链路继续使用 `products`、`releases`、`release_assets`、`release_channels`、`update_packages`、`convert_rules`、`convert_tasks`。

## 本地验证

```bash
cmake --build build

cd web
npm run typecheck
npm run build
```

运行服务后：

```bash
curl http://127.0.0.1:8080/api/v1/projects
curl http://127.0.0.1:8080/api/v1/projects/daily
curl "http://127.0.0.1:8080/api/v1/products/Daily/document?version=latest&channel=stable"
```
